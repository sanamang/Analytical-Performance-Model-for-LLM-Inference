perfmodel explorer

GitHub How it works

An analytical roofline model of transformer inference that also accounts for on-chip SRAM. Pick a model and a chip, then move the sliders to see which operations are limited by compute and which by memory, and what that does to tokens/s and energy. Every number is precomputed by the Python package (perfmodel export-explorer). These are predictions: the pure roofline is an upper bound on throughput.

What this is. Precomputed outputs of the perfmodel Python package over a grid of models × chips × precision × batch × context. Time per op is max(FLOPs / peak, bytes / bandwidth) with SRAM and DRAM as separate ceilings. Energy uses approximate Horowitz (ISSCC 2014, 45 nm) constants and leaves out static power, so read energy as relative.

Caveats. SRAM-X is a hypothetical design point, not a product. GPU L2 is treated as a cache, so nothing is assumed resident. Kernel overhead, overlap and framework effects are excluded unless you add them with the realism knobs. See the README's Limitations section.
